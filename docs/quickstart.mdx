## 1. Install the SDK

<CodeGroup>
```bash npm
npm install @ckb-keyway/react
```

```bash pnpm
pnpm add @ckb-keyway/react
```

```bash yarn
yarn add @ckb-keyway/react
```
</CodeGroup>

## 2. Register your application

Open the [KeyWay developer console](https://ckb-keyway.vercel.app/dashboard), create an application, and add every exact browser origin that will use it. Add local development origins separately from production origins, then copy the public app ID.

## 3. Enable cross-origin isolation

Fiber runs a multithreaded WASM node in the browser. A Next.js application must send these headers:

```ts next.config.ts
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  async headers() {
    return [
      {
        source: "/(.*)",
        headers: [
          { key: "Cross-Origin-Opener-Policy", value: "same-origin" },
          { key: "Cross-Origin-Embedder-Policy", value: "require-corp" },
        ],
      },
    ];
  },
};

export default nextConfig;
```

After deployment, `window.crossOriginIsolated` must be `true`.

## 4. Add the provider

Render `KeyWayProvider` in a client component above every component that uses KeyWay.

```tsx app/providers.tsx
"use client";

import { KeyWayProvider } from "@ckb-keyway/react";

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <KeyWayProvider appId="keyway_..." appName="Acme Pay" theme="light">
      {children}
    </KeyWayProvider>
  );
}
```

```tsx app/layout.tsx
import { Providers } from "./providers";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body><Providers>{children}</Providers></body>
    </html>
  );
}
```

## 5. Add login and wallet state

```tsx app/wallet.tsx
"use client";

import { KeyWayLoginButton, useKeyWay } from "@ckb-keyway/react";

export function Wallet() {
  const { ready, authenticated, connection, status, error } = useKeyWay();

  if (!ready) return <p>Loading login...</p>;

  return (
    <section>
      <KeyWayLoginButton />
      {authenticated && status === "connecting" ? <p>Recovering wallet...</p> : null}
      {connection ? <p>CKB address: {connection.wallet.ckbAddress}</p> : null}
      {error ? <p role="alert">{error.message}</p> : null}
    </section>
  );
}
```

`autoConnect` defaults to `true`. After OTP verification, the provider recovers the wallet, starts the Fiber node, connects testnet relays, and then sets `connection`.

<Info>
  The app ID is public. It identifies the integration and lets KeyWay enforce its registered origins; it is not a secret credential.
</Info>

## 6. Open the application

Select **Log in**, enter an email address, and submit the six-digit code. The same email recovers the same CKB account.
