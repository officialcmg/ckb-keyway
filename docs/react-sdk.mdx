## `KeyWayProvider`

Wrap the part of the React tree that uses KeyWay.

```tsx
<KeyWayProvider
  appId="keyway_..."
  appName="Your app"
  theme="light"
  autoConnect
  onError={(error) => console.error(error)}
  onLifecycle={(event) => console.log(event.stage, event.elapsedMs)}
>
  <App />
</KeyWayProvider>
```

<ParamField path="appId" type="string">
  Public application ID from the KeyWay developer console. SDK requests are accepted only from origins registered to this application.
</ParamField>

<ParamField path="appName" type="string" default="CKB KeyWay">
  Name displayed in the embedded login UI. Limited to 64 characters.
</ParamField>

<ParamField path="theme" type='"light" | "dark"' default="light">
  Appearance of KeyWay's login and funding confirmation modals.
</ParamField>

<ParamField path="autoConnect" type="boolean" default="true">
  Recover the wallet and start Fiber automatically after authentication.
</ParamField>

<ParamField path="confirmFunding" type="ConfirmFunding">
  Optional callback for approving the validated on-chain channel funding transaction. Return `true` to continue to Lit-authorized signing or `false` to abort. When omitted, KeyWay renders its styled built-in confirmation modal.
</ParamField>

<ParamField path="onError" type="(error: Error) => void">
  Receives connection and device-lease failures.
</ParamField>

<ParamField path="onLifecycle" type="(event: KeyWayLifecycleEvent) => void">
  Receives structured wallet recovery, lease, database restore, WASM startup, peer connection, synchronization, and ready events with elapsed milliseconds.
</ParamField>

## `useKeyWay()`

```ts
const {
  ready,
  authenticated,
  user,
  connection,
  wallet,
  walletReady,
  fiberStarting,
  fiberReady,
  fiberError,
  lifecycleStage,
  lifecycleTimings,
  status,
  error,
  login,
  logout,
  connect,
  disconnect,
} = useKeyWay();
```

| Field | Type | Purpose |
| --- | --- | --- |
| `ready` | `boolean` | Stored session validation has finished. |
| `authenticated` | `boolean` | The user has a valid KeyWay session. |
| `user` | `{ id: string }` | Stable authenticated user identity. |
| `connection` | `ConnectedKeyWay \| undefined` | Recovered wallet and running Fiber client. |
| `wallet` | `PublicWallet \| undefined` | Recovered CKB identity, available before Fiber finishes starting. |
| `walletReady` | `boolean` | Wallet recovery has completed. |
| `fiberStarting` | `boolean` | Fiber startup is still in progress. |
| `fiberReady` | `boolean` | Fiber is ready for channels, invoices, and payments. |
| `fiberError` | `Error \| undefined` | Fiber-specific startup or lease failure. |
| `lifecycleStage` | `KeyWayLifecycleStage \| undefined` | Current structured startup stage. |
| `lifecycleTimings` | `Partial<Record<KeyWayLifecycleStage, number>>` | Elapsed milliseconds recorded for reached stages. |
| `status` | `KeyWayStatus` | `idle`, `authenticating`, `connecting`, `connected`, `disconnecting`, or `error`. |
| `error` | `Error \| undefined` | Latest provider connection error. |
| `login()` | `() => void` | Open the email OTP modal. |
| `logout()` | `() => Promise<void>` | Stop Fiber, clear the session, and log out. |
| `connect()` | `() => Promise<ConnectedKeyWay>` | Recover and start KeyWay manually. |
| `disconnect()` | `() => Promise<void>` | Stop Fiber without logging out. |

## `connection`

```ts
type ConnectedKeyWay = {
  keyway: KeyWay;
  wallet: PublicWallet;
  node: NodeInfoResult;
  peers: ListPeersResult["peers"];
  balanceShannons: bigint;
};
```

Use `connection.wallet.ckbAddress` for the recovered address and `connection.keyway` for Fiber operations.

### Recommended client methods

| Method | Purpose |
| --- | --- |
| `getCkbBalance()` | Read indexed on-chain capacity in shannons. |
| `activateCkbChannel(options?, onProgress?)` | Fund a channel with safe defaults or an explicit amount, peer, visibility, and fee rates. |
| `waitForChannelReady(channelId, options?)` | Wait until a funding transaction becomes a usable channel. |
| `listChannels(options)` | Read channels, state, local balance, and remote balance. |
| `getChannels(options?)` | Read normalized lifecycle state and bigint local/remote balances. |
| `closeChannel(channelId, options?)` | Cooperatively or forcibly close a channel with typed failures. |
| `newInvoice(params)` | Create a Fiber invoice. |
| `parseInvoice(params)` | Decode and validate an invoice before payment. |
| `sendPayment(params)` | Start a routed Fiber payment. |
| `preflightPayment(params)` | Dry-run a payment and return route/fee readiness or a typed failure. |
| `waitForPayment(paymentHash, options?)` | Wait for payment success or failure. |
| `listPeers()` | Inspect connected Fiber peers. |
| `nodeInfo()` | Read the local Fiber node identity. |
| `stop()` | Stop the node and release browser/device guards. Prefer provider `disconnect()`. |

## Buttons

`KeyWayLoginButton` toggles login/logout. `KeyWayConnectButton` starts or stops Fiber and opens login first when needed. Both accept normal button attributes and label overrides.

```tsx
<KeyWayLoginButton loginLabel="Continue with email" />
<KeyWayConnectButton connectLabel="Start payments" />
```
