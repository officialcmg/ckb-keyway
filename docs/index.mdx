CKB KeyWay gives a React application email OTP login, a recoverable CKB testnet account, and optional managed or browser Fiber connectivity. Login does not start Fiber.

```bash
npm install @ckb-keyway/react
```

```tsx
"use client";

import {
  KeyWayLoginButton,
  KeyWayProvider,
  useKeyWay,
  useCkbWallet,
} from "@ckb-keyway/react";

export function Providers({ children }: { children: React.ReactNode }) {
  return <KeyWayProvider appId="keyway_..." appName="Your app">{children}</KeyWayProvider>;
}

export function WalletStatus() {
  const { ready, authenticated } = useKeyWay();
  const { address } = useCkbWallet();

  if (!ready) return <p>Loading...</p>;

  return (
    <div>
      <KeyWayLoginButton />
      {authenticated && !address ? <p>Recovering wallet...</p> : null}
      {address ? <p>{address}</p> : null}
    </div>
  );
}
```

## What the SDK handles

- Email OTP UI and session recovery
- Stable CKB account recovery through Lit
- Browser Fiber node startup and testnet peer connection
- Externally funded Fiber channel activation
- Fiber invoices, routed payments, channels, and balances

## Requirements

- React 18.2 or newer
- A modern browser with Web Locks and Web Crypto
- Browser mode additionally requires WebAssembly, IndexedDB, and cross-origin isolation
- CKB testnet funds when opening a channel
